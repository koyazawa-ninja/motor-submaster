        MOTOR SUBMASTER / 操作ガイド

        使い方

        このアプリでできること

        このアプリにはマップ作成、画像制作、NPC設定、ボスデータ、判定・戦闘処理解析の5つのWorkspaceがあります。この項目ではマップ作成を案内します。TRPG用マップは、AIに設計してもらう、空のシートに自分で描く、以前のマップデータを使う、の3通りで用意できます。マップデータを点検してプレビューを確認したら、Excel形式（.xlsx）で保存できます。保存したファイルはExcelやGoogle スプレッドシートで使えます。

        まず試してみたい

        まず試すなら「サンプルを開く」から同梱された6種類のマップを選びます。アプリ起動時は工業街のサンプルが表示され、点検結果とプレビューをすぐ確認できます。

        サンプルから別のマップデータへ入れ替えるときは、「入力を空にする」で入力欄を空にしてから貼り付けられます。

        AIにマップを作ってもらいたい

        1. 「AIに渡す作成指示」を開き、「全文をコピー」または「指示文を保存」を使います。
        2. コピーした指示文の末尾にある「今回のマップ要件」へ、シナリオの概要や希望を書きます。
        3. 指示文を外部の対話AIサービスへ貼り付けて送信します。
        4. AIから返ってきたマップデータを「マップデータ」欄へ貼り付け、「マップを点検・表示」を押します。
        5. プレビューと点検結果を確認し、要修正がなければ「Excel形式（.xlsx）で保存」を押します。

        ヘッダーの「外部リンク保存」では、好みのAIツールや参考サイトのリンクを、ブラウザが許可する範囲でローカル保存できます。

        AIの返答が```jsonのようなコード枠で囲まれていても、そのまま貼り付けられます。

        自分でマップを描きたい

        MapSpec（マップ仕様書）を書かずに自分で描く場合は、「空のマップシートを作る」を押します。横幅（マス）と縦幅（マス）を指定し、「Excel形式で作る」で空の表計算ファイルを作成します。保存したファイルはExcelやGoogle スプレッドシートで直接編集できます。凡例の見本は、セルの色・罫線・文字を決める参考にできます。1マス約1.5〜2mは目安です。

        この手動用ファイルはアプリで再利用するマップデータ（JSON）ではありません。編集したファイルをアプリへ戻してマップデータへ変換する機能はありません。

        以前のマップデータを開きたい

        AIから受け取ったマップデータや、以前に保存したマップデータを使えます。保存済みのマップデータ（JSON / .json）は「マップデータを開く」で選ぶか、「マップデータ」欄へ貼り付けます。点検結果とプレビューを確認し、要修正がなければ「Excel形式（.xlsx）で保存」を押します。必要なら「マップデータを保存」で、アプリで再利用するデータを手元に保存できます。

        マップデータ（JSON）はアプリで再利用するデータ、Excel形式（.xlsx）はExcelやGoogle スプレッドシートで使う資料です。表計算ファイルをアプリで開く機能はありません。

        「要修正」「注意」が出た

        「点検結果」を確認してください。「要修正」は入力を直す必要があり、「Excel形式（.xlsx）で保存」は使えません。入力を直してから、もう一度「マップを点検・表示」を押します。入力を編集中は、前回点検時のプレビューが表示されることがありますが、現在の入力とは未同期です。再点検が成功すると新しい表示へ更新され、入力を空にすると前の表示も消えます。「注意」は確認や助言です。内容を確認し、問題なければ「Excel形式（.xlsx）で保存」を使えます。AIが作ったマップデータであれば、表示された要修正の内容をAIへ渡して修正を頼むこともできます。

        ネヤ式キャラシート参照

        参加PCのネヤ式キャラクターシートをGoogle Sheetsで参照するための補助シートです。URLの貼り付けと初回のアクセス許可は手動で行います。

        1. 「Excelにネヤ式参照シートを追加」をONにして、Excel形式（.xlsx）で保存します。
        2. 保存したファイルをGoogle Sheetsで開くかインポートします。
        3. 追加された参照シートへ、参加PCごとのネヤ式キャラクターシートURLを貼り付けます。
        4. 初回接続時に求められた場合は、Google Sheets上で参照元へのアクセスを許可します。
        5. 表示された値を確認し、「イニシアチブ」から「緊急」までの必要な行のデータ範囲をコピーします。URL欄はコピー範囲に含めません。
        6. Mapの対応する位置へ「値のみ貼り付け」を行います。通常の貼り付けでは参照用の数式もコピーされます。
        7. 転記後のMapは独立して編集できます。「名前：アイコン」やセッション中の値も通常どおり変更できます。

        参照機能はGoogle Sheets向けです。Excelで参照式が評価されなくても、通常のMapはそのまま利用できます。

        NPCを作りたい

        画面上部の「NPCジェネレーター」を選ぶと、NPC作成機能を開けます。マップを作らず、NPCジェネレーターだけ使うこともできます。ここで作ったNPCはMapSpecやマップへ自動では追加されません。

        MapSpecって何？

        MapSpec（マップ仕様書）は、このアプリがAIとの受け渡しや保存に使う専用のマップデータ形式です。通常は自分で書く必要はありません。AIが作ったデータや、以前保存したデータをアプリへ渡すために使います。

        データの扱い

        このアプリに貼り付けたマップデータは、アプリから自動的に外部へ送信されません。ただし、ご自身で外部のAIサービスへ貼り付けた内容は、そのサービスへ送信されます。

        人物資料 / 現地調達

        まず試すなら

        1. 種族（例：人間）、場所・環境（例：ネオン街の路地）、自由入力（例：赤い傘を持つ）はすべて任意です。場所・環境は主に服装や小物、素材、汚れなど人物の背景に影響します。「背景にも反映」は、場所が入力されているときだけ画像背景にも使い、オフまたは場所未入力では単色背景になります。
        2. 一般市民／ニンジャを選び、「すべて生成」で人物を作成します。
        3. 必要な結果を確認して「結果をコピー」を押します。

        画像生成AIへ渡す

        「AI指示文をコピー」を対話AIへ貼り付けると、画像生成用プロンプトが返ります。そのプロンプトを画像生成AIへ渡します。「AI指示文を編集」では、現在のNPCから本文を作るか、NPCの生成結果を使わず白紙から書き始められます。白紙の本文が空白のままではコピーできないため、本文を入力してからコピーしてください。下書きはリロールしても変わりません。

        生成した立ち絵が単色背景なら「透過PNG化の指示をコピー」を使えます。画像と指示を一緒に、画像編集と透過PNGファイル出力に対応するAIへ渡してください。対応状況はAIや利用環境によって異なります。求めるのは市松模様などを描き込んだ画像ではなく、アルファチャンネルで背景が透明なPNGです。

        作業中のデータ

        NPCはマップへ自動追加されません。ページを閉じる前に、必要な結果と下書きをコピーしてください。外部AIへの送信は、ご自身で行います。

        画像資料 / 制作手順

        まず試すなら

        1. サムネイル・挿絵・アイテム画像から用途を選び、内容を入力します。

        サムネイルを仕上げる

        「サムネイルを仕上げる」で背景画像（PNG）を読み込み、タイトルと立ち絵・装飾を重ねます。背景は中央・下端に合わせて切り抜きます。表示タイトルを変えても、制作指示の作品名は変わりません。

        追加した立ち絵や装飾は一覧から選択し、表示・順序・位置・倍率を調整できます。画像上のドラッグと数値入力の両方が使えます。先頭が背面、末尾が前面です。

        タイトル下線・最下端アクセント・AI活用開示は個別に切り替えられます。「完成画像（PNG）を保存」で1280 × 670の画像を保存します。

        挿絵・アイテム画像

        生成した画像は外部AI側で保存・利用してください。この画面での文字・装飾の合成はサムネイル専用です。アイテム画像には、切り抜きやすい単色背景も指定できます。

        単色背景を透過素材にする

        生成した立ち絵やアイテム画像が単色背景なら「透過PNG化の指示をコピー」を使えます。画像と指示を一緒に、画像編集と透過PNGファイル出力に対応するAIへ渡してください。対応状況はAIや利用環境によって異なります。市松模様や別の背景を描き込んだ画像ではなく、アルファチャンネルで背景が透明なPNGを求める指示です。

        画像の上限と保存

        装飾は最大12枚。PNGは1枚16 MiB以下・各辺4096px以下・8,388,608画素以下です。画像展開容量は背景と非表示の装飾も含めた全画像の画素数で、合計24 MP相当まで。一時的な画像展開は32 MP相当までです（1 MP相当＝1,048,576画素）。実際のメモリ使用量ではありません。上限を超える画像を選んでも、直前の仕上がりは残ります。

        制作中の内容は、このページを閉じると失われます。必要な制作指示と完成PNGを保存してください。AIへの自動送信は行いません。

        NPC Data / Encounter Draft

        NPCデータを用意する

        まず試すなら：通常のNPCなら「NPCデータを生成」を選び、レベルと生成数を確認します。

        1. 「NPCを生成」を押します。
        2. 必要なNPCデータをコピーします。
        3. 対応するランダム生成シナリオで使うときだけ、用途を切り替えます。

        シナリオプロフィール

        デッドリー・ヴィジョンズはPC人数に応じた生成・選択と、PC3／PC4以上の人数補正を使います。スカウト部門の日常はPC1／PC2の生成・選択を使い、デッドリー・ヴィジョンズの人数補正は適用しません。

        固定と部分再生成

        残したい出目は固定できます。各表だけを振り直すか、候補単位で固定されていない表を再生成できます。壁やアーチ級D3は条件がなくなると解除されます。出目を確かめたいときは生成記録を開きます。

        基礎データと出撃データ

        「基礎データをコピー」は人数補正前の生成候補をコピーします。「出撃データをコピー」は選択確定後のデータをコピーし、人数補正があるシナリオでは補正後の値を含みます。基礎データはそのまま保持され、補正しても基礎能力と出目は変わりません。ミニオン強化は外部準備が必要で、ミニオン自身の万札は0です。

        まず試すなら

        判定成功率は、調べたいダイス数の行と難易度の列が交わるセルを選びます。1つ目をAに保存 → 条件を変える → Bに保存で比較できます。

        表は1〜30Dを初期表示し、「1〜127Dを表示」で1〜127Dへ広げられます。

        判定成功率を調べる

        1. 「判定成功率」を開きます。
        2. 表からダイス数と難易度を選びます。
        3. 選択した条件の成功率を確認します。
        4. 成功数の内訳と条件比較は最初から表示されます。必要に応じて「出目条件の詳細」を開きます。

        広げた範囲の選択や比較条件は、30Dへ戻しても保持されます。

        出目条件を調べる

        「出目条件」から【6,6】などを選ぶと、その出目が成立する確率を確認できます。「表にも表示」を有効にすると、成功率表の横に同じ条件の確率を表示します。出目条件の成立率と判定成功率は別の値です。

        ダメージを調べる

        1. 「ダメージ解析」を開きます。
        2. 最初からある「攻撃1」を編集するか、プリセットで新しい攻撃を追加します。
        3. 攻撃判定・回避・ダメージを入力します。値を変えると結果は自動更新されます。
        4. 期待ダメージ、0ダメージ率、目標ダメージ以上になる確率を確認します。

        プリセットについて

        プリセットは解析用の初期値です。武器の使用条件、スキル、戦闘スタイルなどは自動では適用しません。実際のルール適用はルールブックと卓の裁定を確認してください。
